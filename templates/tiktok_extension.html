TikTok Chrome Extension

TikTok Extension

Use TikGrab to collect public TikTok profile video data, filter results, export spreadsheets, and search words inside TikTok descriptions directly from Chrome.

What The Extension Can Do

Fetch videos from a profile Open a TikTok profile, then collect videos from that account with metadata such as title, date, duration, views, likes, and thumbnail.
Filter the profile results Limit the scan by date range, minimum or maximum duration, keywords in titles or descriptions, and maximum number of videos.
Select and review videos Select all videos or only specific videos, then open selected TikTok posts in the browser for manual review.
Export and search descriptions Export bulk or search results as CSV, Excel, or JSON, and search TikTok descriptions by one word or multiple words.

How To Install It In Chrome

  1. Click Download Extension ZIP at the bottom of this page and save the file on your computer.
  2. Right-click the ZIP file and choose Extract All.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode in the top-right corner.
  5. Click Load unpacked.
  6. Select the extracted tikgrab-extension folder, the folder that contains manifest.json.
  7. Open a TikTok profile tab, then click the TikGrab extension icon from Chrome's toolbar.
  8. Choose what you want to do: fetch profile videos, filter results, export data, open selected posts, or search descriptions.

Visual Setup Steps

1

Check Developer mode

Open chrome://extensions. If Developer mode is inactive, the switch in the top-right corner is grey.

2

Activate Developer mode

Turn Developer mode on. When it is active, Chrome shows the Load unpacked button.

3

Load the extension folder

Click Load unpacked and choose the extracted tikgrab-extension folder that contains manifest.json.

4

Find TikGrab in Chrome

Click the Extensions icon in Chrome's toolbar, find TikGrab, and use the pin icon if you want it to stay visible.

5

Open a TikTok profile and fetch videos

Open the TikTok profile you want to collect, then open TikGrab. In the Bulk tab, confirm the detected profile and click Fetch Videos.

6

Filter, select, and export results

Open Filters to choose a date range or maximum number of videos. After fetching, select all videos or specific rows, open selected posts, or export the metadata as CSV, Excel, or JSON.

7

Search words in descriptions

Open the Search tab, enter one word or several words, choose whether all words must match, and click Search Descriptions. Matching results can also be exported as CSV, Excel, or JSON.
