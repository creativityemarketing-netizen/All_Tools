Instagram Chrome Extension

Extension Instagram

Extract Instagram profile data, filter posts by date range, export metadata, and download Instagram media directly from Chrome.

What The Extension Can Do

Extract public profile data Extract information from any public Instagram account and save it as an Excel/CSV file. The export includes platform, account, post ID, post URL, caption, published date, media type, likes, comments, media URL, thumbnail URL, and thumbnail.
Extract by date range Choose a start date and end date, then extract only the Instagram posts and reels published inside that selected period.
Download all or filtered media Download all Instagram profile content, or choose a date range and download only the content published during that period. Downloads can be saved as files in a folder or packaged as a ZIP.
Select posts and reels manually Select publications directly from the feed page or reels page, then download only the selected posts or reels.
Search words in descriptions Search inside an Instagram profile using one word or multiple words from post descriptions and captions.

How To Install It In Chrome

  1. Click Download Extension ZIP and save the file on your computer.
  2. Right-click the ZIP file and choose Extract All.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode in the top-right corner.
  5. Click Load unpacked.
  6. Select the extracted extension folder, the folder that contains manifest.json.
  7. Open an Instagram profile, then click the extension icon from Chrome's toolbar.
  8. Choose what you want to do: extract profile data, use a date range, download media, select specific posts, or search inside descriptions.

Visual Setup Steps

1

Check Developer mode

Open chrome://extensions. If Developer mode is inactive, the switch in the top-right corner is grey.

2

Activate Developer mode

Turn Developer mode on. When it is active, Chrome shows the Load unpacked button.

3

Load the extension folder

Click Load unpacked and choose the extracted folder that contains manifest.json.

4

Find the extension menu

Click the Extensions icon in Chrome's toolbar to find installed extensions.

5

Pin Instagram Scraper

Find Instagram Scraper in the menu. To pin the extension in Chrome, click the pin icon shown in the circle.

6

Extract all metadata, or choose a date range

This step is optional. To collect all metadata, open any Instagram account and click Extract Posts. To collect only a specific period, choose the date range first, then extract or download.

7

Select content and search captions

Use this panel on an Instagram profile when you want to select specific content or search captions.

  1. Select: choose publications from the profile, feed, or reels page before downloading.
  2. Description Search: open or close the caption search panel.
  3. Search descriptions: type one or more words, then click Search to find matching captions.
